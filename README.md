his project implements a multimodal classification model, aiming to classify based on two sets of different types of input features (power density, illumination current and pressure, pressure current). The project process includes: 

Data preprocessing: Load data from CSV files, perform label encoding and feature standardization. 

Model Construction: Design a multi-input neural network model to process two sets of input features and fuse them for classification. 

Training and Evaluation: Train the model using the training data and evaluate its performance on the test data. During the training process, record metrics such as accuracy, loss, and confusion matrix. 

Visualization: Generate accuracy and loss curve graphs for the training process, as well as a confusion matrix graph for classification results.
